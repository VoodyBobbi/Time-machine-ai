# Машина времени года на Flask !

Локальный веб-сайт на Flask, который:

- принимает год от пользователя,
- отправляет его в пайплайн GigaChat,
- получает описание ситуации на русском,
- усиливает image prompt,
- генерирует изображение через OpenAI,
- показывает прогресс и результат в браузере.

## Возможности

- поле для ввода года,
- заранее заданные стили изображения,
- прогресс-бар во время генерации,
- повторные запросы без перезапуска сайта,
- история последних генераций,
- просмотр описания и итоговой картинки на одной странице.

## Установка

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Настройка

Создайте и заполните `.env` по образцу `.env.example`.

Обязательные переменные:

- `OPENAI_KEY`
- `GIGACHAT_CREDENTIALS`

## Запуск сайта

```powershell
python .\app.py
```

После запуска откройте:

```text
http://127.0.0.1:5000
```

## CLI режим

Старый CLI тоже сохранён:

```powershell
python .\image_generator.py 2035 --style cinematic_realism
```
